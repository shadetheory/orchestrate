## Featured Projects

### Conduit - Developer Liberation Platform
> *"Break free from corporate toolchain tyranny. Your code, your tools, your rules."*

A Laravel Zero CLI with a microkernel architecture that grows with your needs:

```bash
conduit discover                    # Find community components
conduit install conduit-spotify     # Add music control
conduit ask "where is auth handled?" # AI-powered codebase Q&A
```

**Tech:** Laravel Zero, PHP 8.3, Component Architecture
**Status:** Active Development
**Repo:** [conduit-ui/conduit](https://github.com/conduit-ui/conduit)

## Philosophy

### Developer Wellbeing Intelligence

Most tools optimize for productivity. I'm building tools that optimize for **sustainable development**.

```
conduit: "You've been coding for 4 hours. It's 2:17am.
         Your commit messages are getting shorter.
         Tomorrow-you might regret this.

         Want me to set a wrap-up timer?"
```

This isn't surveillance - it's **self-awareness you control**.

### The Stack

- **Laravel** - Because PHP deserves respect
- **Laravel Zero** - CLI done right
- **Saloon** - HTTP clients that don't suck
- **Vue 3 + Inertia** - SPAs without the API ceremony
- **AI Integration** - Claude, GPT, and beyond

# Deep Analysis: What Should I Focus On?

Run a multi-agent analysis to determine highest-impact priorities.

## Instructions

Deploy multiple agents in parallel to analyze the portfolio:

1. **Launch analysis agents** for each major project area
2. **Cross-reference** findings to identify patterns
3. **Score** projects on: Reach, Differentiation, Completeness, Leverage, Passion
4. **Synthesize** into actionable recommendations

## Agent Deployment Pattern

Use the Task tool to spawn parallel agents:

```
Agent 1: Analyze conduit-ui/conduit - platform potential
Agent 2: Analyze chat app - AI interface value
Agent 3: Analyze API client ecosystem - infrastructure value
Agent 4: Cross-reference patterns across repos
Agent 5: Research market/competition
Agent 6: Score impact potential
```
